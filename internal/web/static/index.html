Threads

click a row to explore its stacks

Linux has no per-thread RSS: all threads share one address space, so pidstat -r -t repeats the process RSS on every row. Here live is sampled heap + anonymous-mmap bytes still held that the thread allocated, which needs an allocation tracer. Memory freed by another thread is credited back to the allocating thread. flt/s counts minor page faults, the pages the thread touched first, and needs no tracer.
