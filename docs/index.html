mhp recordings

Example recordings of mhp, the live memory profiler for MySQL, Percona Server and MariaDB.

Offline copies

Each one is the whole mhp UI with everything it kept, in one file: select time ranges on the chart, explore flame graphs, callers and call trees, check the glibc arenas, or export reports. It runs mhp's own code as WebAssembly, so it needs no server. Files are 6–14 MB; give them a few seconds to load.

Percona Server 9.7 · airportdb

sysbench, then large UPDATEs, a SELECT DISTINCT building a 0.5 GiB temporary table, an index build and a rolled-back 10M-row UPDATE. InnoDB is split into areas: MVCC old row versions, undo, row writes, DDL & index builds. To see the spike, select 18:01:08–18:01:20 UTC on the chart (the chart shows your local time).

MyRocks blob workload · glibc, at the peak

34 GiB RSS for 10 GiB of live allocations: 97 glibc arenas, 24 GiB of them free. The arenas panel shows where. RocksDB is split into block cache, memtables, compaction, MyRocks row encoding and more.
